# MamaCare

MamaCare: Maternal and New Mothers Community Platform
(Repository: iyf-s12-communityhub-team-Daisy10688)

## Project Overview

MamaCare is a maternal and child health community platform designed to support pregnant women and new mothers. The platform aims to provide a supportive digital space where mothers can connect, share experiences, access relevant information, and interact with other members of the community.

## Objectives

- Create a supportive community for pregnant women and new mothers.
- Enable users to create and manage personal profiles.
- Allow members to create, share, and interact with community posts.
- Support discussions through comments.
- Provide a responsive and accessible user experience.

## Core Features

- User Authentication
- User Profiles
- Community Posts and Feed
- Comments and Discussions
- Responsive User Interface

## Technology Stack

**Frontend**
- React
- Vite
- JavaScript
- CSS

**Backend**
- Node.js
- Express.js
- MongoDB Atlas with Mongoose

## Project Structure

The project is organized into separate frontend and backend directories to support modular development and maintainability.

- `frontend/` – React + Vite application
- `backend/` – Express API. See the [backend guide](backend/README.md) for setup, scripts and API details.

## Getting Started
